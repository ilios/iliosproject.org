While you may not be able to actually redeem the coupon at the top of this post, we hope that summer has been feeling as good for you as a free beer coupon might sound.

The team has been heads down working on numerous updates for the system, small and not so small; among the more notable activity - addressing usability, security, and academic / accreditation readiness - are the items listed below.

LTI 1.3: we have updated our LTI components to use the 1.3 LTI protocol, providing better security and more robust management. This will allow out LTI-using schools (and schools interested in using our LTI tools) to be future-proofed against LTI 1.1 end of life, and any potential updates.

Service Tokens: we have completely rebuilt our service / API token architecture, providing a far more robust and manageable service for both individual and B2B connectivity.

Publish workflow: We are currently updating the systems underlying the publication workflow for courses and sessions in the platform, to provide a much better user experience and a more intuitive review mechanism.

Dark Mode: We expect to be launching a Dark Mode for Ilios within the next four weeks, meeting both user requests and industry standards for web applications.

Curriculum Inventory removal: the deprecated AAMC Curriculum Inventory tools in Ilios are now being fully removed from the interface and associated processes; while this should have no impact on any active services, we continue to be cautious in deploying these removals. Underlying data (and historical reports) will remain unmodified and available in the database.
