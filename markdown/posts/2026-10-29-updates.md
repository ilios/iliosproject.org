I'd like to acknowledge the work that the team has been putting in to the platform this last quarter. While much of it has been under the hood, they have been aggressively moving to improve the code infrastructure, providing a much-needed (new) baseline for dependency management and framework maintenance, keeping Ilios current and ready to evolve with the rapidly shifting standards in the code environment.

Among numerous smaller improvements across the platform:
- an overhaul of the tag vocabulary manager, providing a much more user-friendly and intuitive interface for the creation and management of all vocabularies and vocabulary terms that you enter into Ilios for tagging.
- 'dark mode' for Ilios. There is nothing you need to do in Ilios to activate the new dark mode, as it is controlled by the defaults you have set in your personal browser and computer. This provides greater accessibility and visibility for everyone working in the platform.
- an updated and improved the curriculum reporting page, now providing better filtering and management.

We have also completed improvements to the LTI component management and security system, which should help facilitate the use of the Ilios LTI in all current LMS platforms with LTI compliance. If you are not already aware of LTI, it is a standard which allows educational systems to securely interact with one another in a simple way, without sacrificing security, usability, or accessibility. The Ilios LTI allows for the student dashboard to be embedded for direct access in a school's LMS such as Moodle, Canvas, or Sakai, simplifying a learner's navigation across platforms and consolidating their critical curricular engagement. If you are interested in learning more about the Ilios LTI, please let us know with a note to support@iliosproject.org.

Finally, we have improved the workflow for publishing, notably around the bulk publishing of sessions / offerings, to better reflect accuracy of data and usability.

We hope these are useful and that you enjoy the updates!
